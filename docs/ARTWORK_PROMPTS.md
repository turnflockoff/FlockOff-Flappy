## FLOCK OFF plate frame

Design reference: black frame, binary/QR/camera-eye motif, "TURNFLOCKOFF.COM — PRIVACY MATTERS" along the bottom. The cut-out must leave every plate character, state name and registration sticker fully visible.

## Storefront

`docs/storefront/products.html` is generated by the `shop-catalog` MCP server (`render_storefront_html`) from `mcp-servers/shop-catalog/data/products.json`. The donate link is pinned at the top. Add-to-cart buttons are placeholders.

## Not included, on purpose

Products whose function is to cover, obscure or defeat plate/camera reading (e.g. a magnetic "leaf" plate cover) are not documented or catalogued here. Covering a plate character is prohibited under CA Veh. Code §5201(f) and similar laws elsewhere, regardless of "art" or "novelty" labelling; the catalog tool rejects such listings.
